## 兼容性与数据

导出 API 默认为散文，要求已记录的 `nodeId`。需要导出 agent 历史的调用方必须传入 `source: 'sessions'`，且不含 `nodeId`。请同步更新自定义调用方；省略选择时现在返回 `loom/export-unavailable`，不再返回转录。

应用操作增加可忽略的 `plugin:loom/applied-diff` 第 1 版记录，包含有界显示证据，不增加模型输入。现有严格的 `plugin:loom/isolation-end` 载荷不变。读取器仅选择有效隔离记录之后、本会话自有且可识别的第 1 版记录；未知或格式错误的证据会被忽略。旧读取器可忽略新判别值；较早已应用分支的已删除检出差异无法恢复。文件已应用但证据无法刷盘时，操作会返回包含已应用路径的 `loom/worktree-cleanup-failed`，并保留检出。

## 验证与剩余限制

重点回归覆盖真实官方 Harness 服务、独立安装的组合包，以及 React DOM 键盘与渲染行为。模型设置转移样例通过未修改的原版适配器加载；配置示例通过固定 Pi 适配器解析；打包检查扫描所选文件中的私密材料。完整结果见[验证说明](../VERIFICATION.md)。

审查中的提供商访问限制及无余额官方密钥属于环境限制；本记录不声称新增了有余额的官方 API 调用。此前成功的 OpenRouter 验收运行仍是针对特定路由的证据；提供商路由与支持可能变化。桌面版、其他 Harness/SDK 版本、人工翻译复核和新包发布不属于本次本地修复运行。
